Read Me First (project context for evaluator)

This is an intentionally minimal validation prototype for a Ravineo-style Snapchat intelligence workflow. It is optimized for transparency, reproducibility, and quick evaluator understanding rather than polish.

Why Snapchat

  • Public Ads Library path enables fast, reproducible sample ingestion.
  • Lower delivery risk for this assignment timeframe than alternatives tested.
  • Strong fit for ad-transparency proof-of-value in a short prototype cycle.

Choices and reasoning

  • Table-first UI for auditability and low ambiguity.
  • Proxy metrics are explicit; no fake precision for spend/performance.
  • Dual view (`Dashboard` + `Ad Campaigns`) mirrors observed Ravineo usage patterns.

What is real vs inferred

  • Real: ad rows and metadata from local Snap sample JSON files.
  • Inferred: spend ranges, performance-per-spend proxy, category/risk heuristics.
  • Rule: inferred values are directional only and marked as such.

Current state and why

  • Stage: early validation, not production hardening.
  • Dataset timestamp: -
  • Ad rows loaded: -
  • Ads source files: -
  • Known limits: sparse paid sample depth due to rate-limit behavior in collection runs.
